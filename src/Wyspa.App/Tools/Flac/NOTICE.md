# FLAC 1.5.0

Wyspa invokes the unmodified Xiph.Org FLAC command-line encoder as a separate
local process. No compressor download or network connection is required at runtime.

Official project: https://xiph.org/flac/
Official release: https://github.com/xiph/flac/releases/tag/1.5.0

The `Win64/flac.exe` and `Win64/libFLAC.dll` files were extracted from the
official `flac-1.5.0-win.zip` release. `flac.exe` is GPL v2 or later;
`libFLAC.dll` uses the Xiph BSD license. License texts, author credits, upstream
build notes, and the corresponding full source archive `flac-1.5.0.tar.xz`
are distributed alongside the binaries. The source archive contains the upstream
build scripts and source; see README-for-these-builds.txt and the archive README.
