Wyspa 0.9.4 brings together the streaming, appearance and usability improvements tested since 0.9.1.

## Changes

- More responsive Stream Mode: requests target a one-second start cadence while retaining transcript agreement checks and the complete final audio pass.
- Animated red waveform during detected speech and green during quiet listening or pending processing. The waveform disappears after delivery, without waiting for background cleanup.
- Automatic live typing in editable fields even when an editor does not expose accessibility text ranges. No review-before-pasting step; the full dictation continues updating the clipboard as a backup.
- Stream Fix still limits final replacement to the verified passage dictated by Wyspa. Focus changes or manual edits stop further insertion for that session.
- Windows notifications can be turned off under Look & Feel.
- Windows accent colours for controls and selection, neutral light/dark header and navigation surfaces, and clearer borders.
- All 27 question-mark help icons support hover, click and keyboard activation. Settings controls and the main workflows have consistent, wrapped hints, including guidance for disabled options.

## Download and install

Download **WyspaSetup-0.9.4-win-x64.exe** below. Requires Windows x64. The installer checks for the .NET 10 Desktop Runtime and installs it when missing. A Groq API key and an internet connection are required for transcription. Existing settings and encrypted API-key storage use the same locations as previous versions.

## Validation and testing limits

160 automated tests passed with zero failures or skips and native FLAC enabled. Native WPF checks passed for help interaction, settings persistence, notification gating, theme/accent behaviour and recorder overlay. Earlier native validation of the included streaming changes covered Word, Edge text areas, browser rich-text fields, WPF fields and a field without accessibility text ranges.

The installer and packaged application were verified. Clean-machine installation, upgrade/uninstall, physical microphone acceptance, long dictations and broad editor compatibility still need hands-on testing. More frequent streaming requests remain subject to the Groq account's rate limits.
