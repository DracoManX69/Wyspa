Wyspa 0.9.5 adds managed local transcription, model comparisons and personalized wake setup.

## Local transcription without an account

- Fresh installations include Zipformer English 20M and default to local Stream Mode. Training is optional; a Groq account is not required for local transcription.
- The Model Manager has 25 local choices, including Whisper, NVIDIA Parakeet v2/v3, Parakeet Redux ONNX, Moonshine, SenseVoice, Faster-Whisper and streaming Zipformer. It shows names, weight sizes, status, model information and per-model progress, with individual/batch install and removal.
- Optional models and managed runtimes download and verify inside the app. No terminal, system Python, pip or PATH changes are required. Model weights are under 1.5 GB; shared runtime/CUDA downloads have separate sizes.
- Compare Models tests all installed models, scores and highlights the winner, and records separate supported CPU/GPU results. GPU permission allows compatible Vulkan/CUDA acceleration; measured results or failures can still choose CPU. Optional Groq comparison uses the best local result.
- Selected local processing covers dictation, SmartListen, Stream Mode, Scratchpad, Audio Files, Conversation and YouTube transcription. Cloud summaries, re-writing, AI intent interpretation and Stream Fix remain Groq features. YouTube media downloads still require internet access.

## Personalized wake setup and simpler controls

- An optional SmartListen popup wizard uses 14 alternating wake/non-wake readings. Three isolated phrase examples are separated by varied requests, everyday speech and similar-word negatives.
- Wyspa learns repeated pronunciation variants, adjusts strictness and checks fresh recordings before applying the profile. Samples can finish after a natural pause; Finish/Discard/Pause remain available.
- Wake detection runs locally through a dedicated small keyword model and independent word verification. Actual dictation uses the selected provider/model. The ready cue marks when to begin dictating.
- One configurable hotkey follows Toggle, Hold to Talk or SmartListen. Media Handling applies only to hotkey-owned sessions. SmartListen-specific controls appear only in SmartListen.
- Speech-based recording stopping fixes wake sessions that could remain open after silence, including when the start threshold was zero.

## Download and install

Download **WyspaSetup-0.9.5-win-x64.exe** below. Windows x64 is required. Setup downloads and verifies the x64 .NET 10 Desktop Runtime and Microsoft C++ runtime only when missing. The included local speech model works offline after prerequisites are available; optional model/runtime downloads and Groq features require internet access.

Existing installations retain their saved provider, settings, protected API key and notes. Run the new installer over the existing installation. To try local processing, open Settings → Local models. To use the new wake readings, select SmartListen, then Experimental → Wake Voice → Review wake setup → Learn a fresh profile.

## Validation and limits

265 release tests passed with zero failures/skips and a native FLAC test encoder enabled. A fresh source publish matched the accepted App/Core/Infrastructure assemblies byte for byte. Targeted native Windows checks covered the Fluent UI, model controls, hotkey/media handling, wake setup and silence behavior.

The final controlled wake pipeline accepted 18 positive synthesized recordings and rejected 30 non-wake recordings, and repeated that result on reduced-volume/noise-augmented copies. Median positive processing was approximately 140 ms on the test host versus approximately 181 ms for the comparison baseline. These are accelerated synthesized-fixture processing measurements, not live microphone latency or universal accuracy estimates.

Wake/speaker identification remain experimental. Real accents, microphones, room noise, media echo, long unattended false-trigger rates, broad hardware/editor compatibility, high contrast and clean-machine install/upgrade/uninstall still need hands-on acceptance. No claim of 99.99% or Alexa-equivalent accuracy is made. Detailed source validation and limitations are in `docs/V095_VALIDATION.md`, with local/wake research in the accompanying documentation.
