WyspaFluent 0.9.6 adds automatic timestamped CSV exports for uploaded audio files.

## Timestamped Audio Files

- The transcript preview, copied transcript and text export include start/end timestamps for each speech segment.
- Every completed recording automatically creates a CSV in `%AppData%\Wyspa\FileTranscripts`, with one speech segment per row and `start,end,text` columns. Times use `HH:MM:SS.mmm` relative to the original recording, including silence and split-upload offsets.
- **Open CSV** opens the saved file in your default spreadsheet app. **Save CSV…** lets you save a copy to another folder.
- CSV files use UTF-8 with a BOM, with escaping for commas, quotes and line breaks. Unique filenames preserve earlier exports. A silent recording produces a header-only CSV.
- Local transcription uses the model's available timed words/spans; accuracy and granularity depend on the model. A model returning one coarse span produces one row.
- Cancellation preserves completed CSVs and partial transcript text. Retrying a partial recording starts it again without duplicating the partial result. If automatic saving fails, the completed transcript can be exported manually without another transcription request.

Completed CSVs are stored locally until you delete them. Clearing the queue does not delete exports. Conversation and YouTube workflows and saved setting identifiers are unchanged.

## Download and install

Download **WyspaSetup-0.9.6-win-x64.exe** below and run it over the existing installation. Windows x64 is required. Setup downloads and verifies the x64 .NET 10 Desktop Runtime and Microsoft C++ runtime only when missing. Saved provider preferences, settings, protected API key and notes are preserved.
