Missing callbacks still expire the clock. The fallback has an absolute positive floor. Neural activity uses one below-normal worker, bounded PCM queue and no saved speech segments. Stale frames from an earlier session cannot hold the next capture open. Non-streaming dictation now raises CaptureStopped immediately after microphone stop, matching stream lifecycle semantics for wake rearming and hotkey-owned media restoration.

Research sources: Amazon's public two-stage on-device wake/background modeling work, Google's streaming KWS work, and sherpa-onnx/Silero documentation (linked in LOCAL_MODELS.md). Wake keyword processing now runs outside the WPF dispatcher on a persistent below-normal worker; it no longer creates a new thread for every monitor frame.
